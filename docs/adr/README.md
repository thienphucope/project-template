# Architecture Decision Records (ADRs)

Đặt các file ADR tại đây theo thứ tự `0001-<slug>.md`, `0002-<slug>.md`...

Chỉ tạo ADR khi quyết định thỏa **cả 3 điều kiện**:
1. **Khó đảo ngược** (chi phí đổi hướng sau này lớn).
2. **Dễ gây khó hiểu nếu thiếu ngữ cảnh** (người đọc sau sẽ tự hỏi *"tại sao lại làm kiểu này?"*).
3. **Kết quả của một trade-off thật** (đã cân nhắc nhiều phương án và chọn một vì lý do cụ thể).

## Mẫu tối giản (`0001-example.md`)

```markdown
# <Tiêu đề ngắn của quyết định>

<1–3 câu: bối cảnh, ta đã quyết định gì, và vì sao.>
```

*(Chỉ thêm `Status`, `Considered Options`, `Consequences` khi thực sự mang lại giá trị.)*
